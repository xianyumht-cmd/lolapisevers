# 大区代码参考（cross_query / keepalive）

`KEEPALIVE_TEST_REGION` 建议填代码，不填中文名。  
`cross_query` 接口支持中文大区名和代码两种传法。

## 推荐写法

- `KEEPALIVE_TEST_NAME`：尽量用英文/数字账号（避免脚本文件编码问题）
- `KEEPALIVE_TEST_REGION`：填代码（如 `CQ100`）

## app_env.ps1 示例

```powershell
$env:KEEPALIVE_TEST_NAME = "testplayer#12345"
$env:KEEPALIVE_TEST_REGION = "CQ100"
```

如果你一定要用中文大区名，也可以，但建议只用于接口调用参数，不建议写进保活脚本配置文件。
