## 1. 总目标

将 6178 从旧页面与导航注入并存的过渡实现，逐步重构为统一运维控制台，同时保持现有后端 API、配置 Schema、Secret 规则、Provider 协议、插件协议和公开消息格式稳定。

## 2. 执行原则

1. 所有生产操作继续使用真实后端 API。
2. 页面统一使用共享 Shell、设计令牌和组件。
3. 静态资源全部进入离线部署包，不依赖外部 CDN。
4. Secret 和 Token 不回显，掩码保存必须保留原值。
5. 最终页面 JavaScript 必须进入 CI 语法检查。
6. 每一阶段均需 Linux、Windows、PowerShell 5.1、依赖审计和 Windows 实机验收。
7. 旧界面处理前必须完成真实功能与生产依赖盘点，不能只隐藏入口。
